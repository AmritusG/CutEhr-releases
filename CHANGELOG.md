# Changelog

## 0.1.0 — 2026-11-15

The first public release.

- **CutEhr**: live person cutout and matte, skeleton / hands / face overlays, per-person colours and mattes, edge treatments (Edge
  Refine, Fill Holes, Speck Removal, Temporal Smooth, Mask Motion Comp, Edge Glow), live colour correction with automatic white balance
  (including white balance from skin), person-only or background-only correction, a detection boost for dark or smoky stages, and a
  Picture + Mask in Alpha output for chaining.
- **GradEhr**: the same colour corrector as its own effect for any feed.
- Apple silicon only, macOS 12 or later. The bundles are signed with a Developer ID and notarised by Apple.
